# ECOCIVIX AI — ML Service Foundation & Priority Classification

This repository subtree contains the machine learning foundation for ECOCIVIX AI, providing a fine-tuned transformer classifier for citizen issue priority prediction (`LOW`, `MEDIUM`, `HIGH`, `CRITICAL`).

## Model Choice: `distilbert-base-uncased`

We selected `distilbert-base-uncased` because:
1. **Targeted for Short Text**: Citizen issue titles and descriptions are short-to-medium length texts ($<128$ tokens).
2. **CPU & Edge Feasible**: DistilBERT retains 97% of BERT's language understanding while being 40% smaller and 60% faster, allowing fast CPU/lightweight server inference.
3. **Robust Pre-training & Documentation**: Widely supported by Hugging Face Transformers with stable fine-tuning characteristics.

## Execution Pipeline

To run data preparation, model training, evaluation, and inference, run the following commands from `ml-service/`:

```bash
# 1. Install Dependencies
pip install -r requirements.txt

# 2. Prepare Data & Generate Splits
python -m src.data_prep --in data/raw --out data/splits

# 3. Fine-Tune DistilBERT Model
python -m src.train --config config/train_config.yaml

# 4. Evaluate Model on Frozen Test Set
python -m src.evaluate

# 5. Run Single Issue Priority Prediction
python -m src.predict --title "Exposed Live Wire" --description "Sparking high-voltage wire hanging near school gate."
```
