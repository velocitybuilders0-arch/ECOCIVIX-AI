# ECOCIVIX AI — Dataset Splits Documentation

This directory contains the train, validation, and test dataset splits generated by `src/data_prep.py`.

## Split Strategy

- **Train Set (`train.jsonl`)**: 70% of dataset records.
- **Validation Set (`val.jsonl`)**: 15% of dataset records.
- **Test Set (`test.jsonl`)**: 15% of dataset records.

## Split Generation Rules

1. **Stratification**: Class distributions (LOW, MEDIUM, HIGH, CRITICAL) are preserved across all three splits.
2. **Fixed Random Seed**: Splitting is executed with `seed: 42` for strict reproducibility.
3. **Data Leakage Prohibition**:
   - No duplicate `(title, description)` tuples exist across splits.
   - No near-duplicate pairs (string similarity $\ge 0.9$) exist across splits.
   - `synthetic_paraphrase` records are never permitted in `test.jsonl`.
4. **Frozen Test Set**: `test.jsonl` is strictly frozen and must NOT be used during model training or hyperparameter tuning.
